---
title: "概述"
description: "让智能体用语音与用户对话，并在对话中调用工具完成任务"
---

<Warning>
实时语音智能体目前为实验性功能，接口在后续版本中可能调整。
</Warning>

实时语音智能体是指以语音作为输入与输出的智能体：它持续听取用户说话，用语音作出回应，并在对话过程中调用工具完成任务，而不是等一条完整的文字消息到达后再回复。

根据技术实现方式，可以分为以下两种：

| 实现 | 工作方式 | 特点 |
|------|----------|------|
| 全双工（Speech-to-Speech） | 音频直接进出一个实时语音模型，识别、理解与合成都在模型内部完成 | 延迟低，保留语气与情绪；可选模型较少，上下文按轮数限制 |
| 级联（ASR + LLM + TTS） | 语音识别转成文字交给 `Agent`，回复再由语音合成播放 | 可复用任意文字模型与现有智能体的全部能力；延迟略高 |

AgentScope 目前支持全双工方案，用法参见[全双工语音智能体](/versions/2.0.8dev/zh/building-blocks/realtime/full-duplex)；级联方案即将上线。

两种方案共用同一套智能体能力：

| 能力 | 说明 |
|------|------|
| 回合检测 | 通过语音活动检测（VAD）判断用户何时开口、何时说完，以此划分对话回合；可以由模型 API 完成，也可以传入本地 VAD |
| 打断 | 用户开口即停止当前回复，上下文中只保留用户实际听到的部分；也可以由代码主动打断 |
| 工具调用 | 复用 `Toolkit` 与权限系统，在语音对话中执行工具 |
| 人机交互 | 需要用户确认的工具调用发出确认事件，语音流不中断，确认结果通过 `send()` 送回 |
| 断线恢复 | 模型 API 关闭会话后，用户下一句话自动重连，对话历史保留在智能体状态中 |
| 事件流 | 产出与 `Agent.reply_stream` 相同的智能体事件，文字智能体的事件处理逻辑可以直接复用 |
